# Corpus-derived Writing & Visual Findings — V4.5

本文件记录从当前优秀论文语料中抽取的**可迁移共性**。不要求后续论文模仿某一篇论文的具体配色、算法或章节编号。

## 1. 叙事

代表性优秀论文普遍把多问组织成统一系统逐层加约束，而不是三问各套一套算法。例如：
- 问题一建立基础空间/资源模型；
- 问题二加入动态取送/资源复用；
- 问题三再加入时间窗与具体资源排班。

## 2. 结果证据链

常见强结构：

`Baseline → 中间阶段 → Final → Bound/Gap → 结构解释 → 独立验证`

优化价值被分解到阶段，不只报最终值。

## 3. 语言

优秀论文会主动限定证据边界：
- 候选池最优 ≠ 原问题全局最优；
- 无受控消融时不做70/30这类伪精确贡献拆分；
- 结果和机制分开陈述。

## 4. 图表

观察到的有效实践：
- 低饱和深蓝/浅蓝 + 鲑红/灰；
- 白/浅灰底；
- 浅灰细网格；
- 关闭top/right外框；
- 分组柱常使用约0.19–0.23的窄柱；
- 图例放到不遮挡数据的位置；
- 气泡图、热力图、分布图、路线骨架各自承担不同机制；
- 多面板把“局部机制”和“全局证据”放在同一逻辑单元。

## 5. 不照搬的部分

- 某篇论文使用红蓝热力图，并不意味着所有非负频数都应用发散色；
- 某篇使用柱状图，并不代表类别多时仍应使用竖柱；
- 具体字体、颜色、页眉等必须服从当前比赛规则与全文统一性。

V4.5 因此采用“共性原则 + 图型适配”，而不是视觉抄写。
