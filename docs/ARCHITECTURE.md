# Architecture

```text
SKILL.md
   ↓
MASTER_ROUTER.md
   ├── M0 Project Control
   ├── M1 Problem/Data/Benchmark
   ├── M2 Model Design
   ├── M3 Solving & Optimization
   ↕
   ├── M4 Validation & Experiments
   ├── M5 Paper Engineering
   └── M6 Visual/References/Submission
```

M3 与 M4 是高频反馈循环。其余模块主要是阶段 Gate。

模板目录提供：

- Project Status
- Section Contract
- Reference Ledger
- Figure Card
- Delta Matrix
- Iteration Report

设计目的不是增加流程负担，而是让 AI 在复杂任务中只加载当前必要规则。
