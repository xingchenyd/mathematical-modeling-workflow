# V4.5 Narrative & Visual Grammar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把优秀论文级叙事、语言和视觉语法整体融合进现有数学建模工作流，而不新增独立 M8。

**Architecture:** M1 生成叙事种子，M4 建 Evidence Storyboard，M5 承担逐节叙事与语言协议，M6 承担图型决策和统一视觉样式；B5 自动继承。共享的模板和绘图工具放在 templates/scripts/docs 下。

**Tech Stack:** Markdown, Python 3, matplotlib, NumPy, LaTeX-oriented figure export.

**Spec:** `docs/superpowers/specs/2026-09-07-v4.5-narrative-visual-grammar-design.md`

## Global Constraints

- 不新增 M8；
- 不削弱 V4.4 的 Solution Quality Contract / Bound / Gap / Validator；
- 湖南赛区 V4.3.3 定制规则继续有效；
- 数字/百分比默认不加粗，只突出具体核心算法；
- 图表不是装饰：每张图必须绑定 Claim；
- 默认 LaTeX 原生可搜索 PDF；
- 不允许为了“好看”制造无证据视觉结论。
