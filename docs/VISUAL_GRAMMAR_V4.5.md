# Visual Grammar — V4.5

## 目标

让任何题型的论文图具有统一、克制、证据导向的视觉语言。

## 核心语法

`Claim → Visual Question → Chart Family → Semantic Color → Final-size Audit`

## 默认语义色

- Final: `#355F8A`
- Alternative: `#5D8DB8`
- Light: `#A7C2DC`
- Baseline: `#737B86`
- Improvement: `#5C8D75`
- Secondary: `#C9824B`
- Risk: `#D46A65`
- Severe risk: `#A94E4A`
- Special: `#8B6FA8`
- Grid: `#D2D7DD`
- Text: `#2F3E4D`

## 图型规则摘要

- 多类别排名：横向dot/bar；
- 两方案成对比较：dumbbell/slope；
- 多阶段优化：waterfall/contribution；
- 两目标权衡：Pareto scatter；
- OD/矩阵：heatmap；
- 调度：Gantt；
- 路线动态载荷：step/stacked route profile；
- 分布：box/violin/ECDF；
- 收敛：best-so-far + bound；
- 空间：真实地图或明确标记为MDS/示意。

## 论文图与表

- 表：精确值；
- 图：模式/机制；
- 不能重复同一信息。

## 柱宽

- 单系列 0.45–0.60；
- 双系列 0.28–0.34；
- 3–4系列 0.18–0.25。

## 输出

线图优先 PDF/SVG，位图 300–400dpi，同时保留 source CSV。
