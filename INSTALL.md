# Installation

## Codex / cross-runtime Agent Skills

Copy this directory to:

```bash
mkdir -p ~/.agents/skills
cp -R mathematical-modeling-workflow ~/.agents/skills/mathematical-modeling-workflow
```

Do not rename the installed skill directory; the Agent Skills specification requires the directory name to match `name: mathematical-modeling-workflow`.

## GitHub

The GitHub repository may keep the Chinese display/repository name `数学建模工作流`. When installing it as an Agent Skill, clone/copy the skill into a local directory named `mathematical-modeling-workflow`.
